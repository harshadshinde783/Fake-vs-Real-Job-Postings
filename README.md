# Fake vs Real Job Postings Analysis

## 📌 Project Overview
This project analyzes fake and real job postings to identify key patterns that help detect fraudulent job listings.

## 📊 Power BI Dashboard

![Fake vs Real Job Postings Dashboard]()


## 🎯 Objective
- Clean and prepare job posting data
- Perform exploratory data analysis
- Build an interactive Power BI dashboard
- Identify indicators of fake job postings

## 🗂 Dataset
- ~3000 records, 25 columns
- Target column: `is_fake` (0 = Real, 1 = Fake)

## 🧹 Data Cleaning Steps
- Split location into city and country
- Handled missing company names
- Created logo status column
- Converted fake indicator into readable job type

## 📊 Tools Used
- Microsoft Excel
- Power BI Desktop

## 📈 Key Insights
- Fake jobs are common in internships & part-time roles
- Missing salary information indicates higher fraud risk
- Jobs without company logos are more likely fake
